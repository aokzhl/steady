# Steady

Нативный macOS-клиент. Первый срез реализует гостевые задачи: создание, выполнение, отмену и локальное восстановление после перезапуска. Текущий тикет: https://github.com/aokzhl/steady/issues/2.

## Разработка

Нужны macOS 14+, Apple Command Line Tools со Swift **6.2.3** и mise. Полный Xcode для этого среза не требуется. Версия инструментов фиксируется в `mise.toml` и проверяется перед командами; обновление выбранного SDK/Swift требует проверки совместимости.

В корне репозитория:

```sh
mise trust
mise run check
mise run test
mise run build
mise run run
```

- `check` собирает и проверяет типы, считая предупреждения ошибками.
- `test` запускает Swift Testing через публичный TaskWorkspace с настоящими временными SQLite. Для CLT автоматически настраиваются пути к встроенному Testing и его макросам; отсутствующий в CLT Foundation overlay не используется.
- `build` создаёт локально подписанную `apps/focus/macos/.build/Steady.app`. Её можно открыть двойным нажатием.
- `run` собирает и запускает ту же .app; процесс работает до выхода из приложения.

При необходимости команды доступны напрямую: `bash tooling/macos.sh check`, `test`, `build`, `run`. Одиночная проверка: `bash tooling/macos.sh test --filter createdTaskSurvivesReopeningTheDatabase`.

## Данные

Гостевые данные: `~/Library/Application Support/Steady/guest/steady.sqlite`. Задача и выполнение имеют разные UUID. Плановый день сохраняется вместе с часовым поясом, отметка выполнения — как точный момент без длительности. Создание задачи/выполнения и изменение состояния используют транзакции. Первая миграция задаёт версию 1; более новая версия или повреждённый файл дают ошибку без сброса базы.

Для отдельного пространства разработки или ручной проверки задайте другую базовую папку:

```sh
STEADY_DATA_DIRECTORY=/tmp/steady-manual-check mise run run
```

Внутри неё создаётся собственная папка `guest`. Команда не импортирует данные, не использует аккаунты и не обращается к backend. Автоматические тесты создают уникальные временные папки и не затрагивают обычную гостевую базу.

После ошибки сохранения введённое название остаётся в форме; кнопку сохранения можно нажать повторно. Закрытие формы сохраняет ввод в памяти процесса. Долговременный черновик, проекты, фильтры, повторы, инструменты времени и backend относятся к следующим задачам.

Техническая спецификация среза: [Issue #2 — первый локальный сценарий](docs/specs/2026-11-14-issue-2-local-tasks.md). Общие требования: [спецификация MVP](https://github.com/aokzhl/steady/issues/1).
