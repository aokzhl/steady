## Новое направление: список задач и детали

[Открыть интерактивные варианты](task-first-variants.html) · [Открыть в Open Design](http://127.0.0.1:61620/projects/steady-focus-macos-design/conversations/855851c3-66e8-4508-b787-327dc5b77c22/files/task-first-variants.html).

Главный экран показывает задачи с профилем и краткой информацией об отработанном времени. Выбор задачи открывает детали с названием, заметками, профилем и запуском помодоро.

- **A — Список и детали:** постоянный список слева, детали справа. [Превью](task-first-A.jpg).
- **B — Детали по клику:** список и всплывающая панель выбранной задачи. [Превью](task-first-B.jpg).
- **C — Внутри списка:** детали раскрываются под строкой задачи. [Превью](task-first-C.jpg).
- [Пример блокировки запуска при активной сессии](task-first-locked.jpg).

Выбранная задача отделена от задачи текущей сессии. Просмотр и редактирование другой задачи не меняют её владельца. Пока сессия работает, находится на паузе или на отдыхе, новый запуск заблокирован с объяснением и переходом к текущей задаче. Остановка освобождает запуск. Управление активной сессией находится в закреплённой нижней полосе.

Снизу вне приложения расположены переключатель вариантов и состояния «Без сессии» / «Есть сессия». Это демонстрационный прототип предыдущего этапа; актуальная принятая основа v1 указана выше.

Проверены независимость выбора задачи от владельца сессии, блокировка запуска во всех вариантах, пауза и отдых, освобождение запуска после остановки, сохранение профиля активной сессии при изменении другой задачи, возврат к владельцу и повторное приращение времени. Окна проверены при 1280×800 и 1440×1000. Данные хранятся в памяти страницы.

## Предыдущий полный макет

Новый интерактивный макет создан через Open Design MCP на основе выбранного тёмного направления Workspace 02. Исходный проект Open Design сохранён отдельно.

- [Открыть проект в Open Design](http://127.0.0.1:61620/projects/steady-focus-macos-design/conversations/855851c3-66e8-4508-b787-327dc5b77c22/files/index.html).
- [Автономная локальная копия](index.html).
- [Превью основного экрана](preview.jpg).

Ссылка Open Design действует при работающем локальном приложении; адрес может измениться после его перезапуска. Локальная копия открывается как обычный HTML-файл без установки зависимостей.

В макете есть основной экран с задачами и таймером, профили с редактированием, история, настройки и демонстрационные формы входа и импорта гостевых данных. Панель у моноброви раскрывается при наведении и предоставляет паузу, остановку, отдых и изменение времени от −20 до +20 минут. Повторное применение повторяет выбранное приращение.

Верхние переключатели показывают состояния дизайна: работа, монобровь, изменение времени, отдых, отсутствие сети и вход. Данные и действия демонстрационные; подключения к backend нет, состояние сохраняется только в текущем сеансе страницы. Это визуальный ориентир для реализации [MVP](../../docs/MVP.md).

Проверены относительное изменение времени и повторное применение, возврат с отдыха с сохранением остатка, остановка, Escape для popover, создание профиля, история без сети и демонстрационный вход с предложением импорта. Основной экран проверен в браузере; экспорт соответствует сохранённой версии Open Design.
