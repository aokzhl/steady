# #15 verification

Automated checks use the accepted public TaskWorkspace seam with real temporary SQLite and injected time/calendar. StopwatchTests cover:

- 3 active minutes + 10 paused minutes + 4 active minutes = 7 recorded minutes, same run, real UTC segment boundaries, initial historical zone retained.
- Paused session prevents a second launch; repeated pause/resume/stop does not duplicate work.
- Completing another task leaves its owner running; completing the owner atomically saves actual work and completion.
- Free consecutive 10 + 15 minute launches retain distinct run/result IDs across reopen.
- Write failure leaves completion/history unchanged, pauses measured work in memory, and successful retry excludes storage-error downtime.
- Reopening an unfinished run restores it paused at its last explicit committed boundary, excluding process absence.
- Migration from v2 preserves an existing task and creation draft, then supports new stopwatch work.

The time API test initially failed to compile before implementation. The failed-write test initially observed running time/690 seconds instead of paused/90 seconds; the restart test initially observed running time/820 seconds instead of paused/180 seconds. Each passed after its behavior was implemented.

`bash tooling/macos.sh test`: 29 tests passed across 3 suites. `bash tooling/macos.sh check` passed with warnings as errors; `bash tooling/macos.sh build` produced the signed native app. `git diff --check` passed. Native interaction verification is performed by the coordinating agent in a separate data directory. Periodic crash checkpoints and system-event pauses remain #18.
