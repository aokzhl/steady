## Review fixes

- Failed commands capture one instant for the SQL write and the in-memory paused snapshot. A public-workspace regression advances the injected clock after the command instant while real SQLite is unavailable: it first failed with 690 seconds instead of 90, then passed with 90 seconds retained through retry and reopen.
- Owner completion and explicit Stop share run-closing logic. The public regression starts at UTC epoch 1000, pauses at 1100, resumes at 1200 and closes after a clock rollback to 1150. Both paths persist a run end and final segment end of 1200 with 100 active seconds; completion keeps its actual command timestamp of 1150. Owner completion first failed with a run end of 1150.
- “К текущей задаче” is available in the session bar and the blocked tool menu when the session has an existing owner. It saves pending details and any open creation draft before changing project context and opening the owner's details. Save failure retains the current editor and inputs. Free sessions expose no owner navigation.

After these fixes, `bash tooling/macos.sh test` passed 44 tests across five suites, `check` passed with warnings as errors, `build` produced the signed native app, and `git diff --check` passed. No migration was changed. Native navigation verification remains with the coordinating agent: check running/paused owner navigation from another project and blocked-launch menu, unsaved/invalid details and creation draft handling, and absence of owner navigation for free sessions. No app was launched by the fix implementer.
