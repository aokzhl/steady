# Issue #8 — проверка повторов

Автоматическая граница: публичный TaskWorkspace, реальные временные SQLite, повторное открытие, управляемые now/calendar. Родительский агент выполняет независимые Standards/Spec ревью и нативную проверку после интеграции.

Вертикальные red/green срезы:

- Ежедневная серия: первоначальный тест не компилировался без публичного API; после реализации подтвердил независимые отметки, пропуски без долга и стабильные UUID после открытия.
- Изменение серии с настоящим запуском секундомера на 45 секунд: первоначально воспроизведено удаление владельца результата (SQLite foreign-key failure). Изменение сохраняет владельцев actual time-tool runs, выполненные экземпляры и явные переносы, включая два выполнения на одном дне.
- Преобразование разового дела без даты в повтор: обнаружена потеря исходного UUID. Исправлено присвоение исходному выполнению текущего календарного дня.
- Переход зоны: обнаружено сохранение старой зоны у предварительно созданного будущего периода. Исправлено принятие текущей зоны до начала периода с отдельной фиксацией исторических периодов.
- Далёкое будущее: первоначально отсутствовал ближайший экземпляр серии со стартом позже ближайшей недели. Исправлена граница материализации относительно старта серии.

Дополнительно проверяются будни и выбранные дни через DST, воскресенье/понедельник и Новый год; прошедший старт; историческая зона при переходе часов назад; общие rich note/проект/метки/приоритет; возобновление черновика; отдельная база без чужих данных; недопустимые даты/пустые и посторонние дни недели; неизвестный UUID; ошибка записи с откатом и повтором. Фикстуры v5/v6/v7 сохраняют UUID, завершение с дробными секундами, rich text, явные параметры черновика и реальные временные результаты при миграции.

Команды в worktree: `bash tooling/macos.sh check`, `bash tooling/macos.sh test`, `bash tooling/macos.sh build`. Проверки успешны: warnings-as-errors check, все 75 тестов в 8 наборах и сборка локально подписанного Steady.app. Приложение этим агентом не запускалось; нативное QA остаётся у координатора.
