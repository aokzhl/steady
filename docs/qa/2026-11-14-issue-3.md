# Проверка MVP 02 — Issue #3

Дата: 14 ноября 2026 года. Среда: macOS 26.6.2 arm64, Apple Swift 6.2.3, Command Line Tools. Минимальная macOS приложения — 14; отдельный Mac с macOS 14 не использовался.

## Автоматические проверки

- `mise run check`: успешно, предупреждения считаются ошибками.
- `mise run test`: 23 теста в двух наборах прошли, включая 10 новых тестов TaskEditingTests с параметризованными случаями.
- `mise run build`, проверка подписи .app, plist и синтаксиса сборочного скрипта: успешно.
- `git diff --check`: успешно.

Тесты используют публичный TaskWorkspace, настоящие временные базы SQLite и повторное открытие новым экземпляром. Проверены переименование без изменения UUID/дня/зоны/отметки выполнения, все приоритеты без перестановки списка, долговременный черновик, создание с очисткой черновика, удаление, недопустимый ввод, миграция базы версии 1, изоляция гостевых пространств и настоящая ошибка записи с повтором. Устаревший экземпляр черновика не создаёт повторную задачу.

До реализации отдельно получены падающие проверки переименования, приоритета, долговременного черновика и создания из него. Дополнительный тест обнаружил усечение черновика на NUL: после исправления UTF-8 сохраняется целиком, а создание из недопустимого названия отклоняется.

## Нативная проверка

Приложение запускалось с отдельной временной папкой через STEADY_DATA_DIRECTORY. Тестовый ввод и изменения файловой системы относились только к этой папке.

| Сценарий | Результат |
| --- | --- |
| Cmd+N в пустом пространстве | Создание справа, фокус в названии, приоритет «Без приоритета» |
| Ввод и выбор «Высокий», закрытие формы, полный выход и запуск | Cmd+N восстанавливает название и приоритет; задача ещё не создана |
| Создание из восстановленного черновика | Одна задача, её детали открыты; следующий черновик пустой, приоритет «Без приоритета» |
| Переименование по Enter | Строка и детали сразу показывают новое название |
| Escape во время правки названия | Восстанавливается последнее сохранённое значение |
| Повторный выбор той же строки во время правки | Новое название одинаково в строке и деталях |
| Название из пробелов и попытка открыть создание | Ошибка валидации, прежняя задача не меняется, введённое значение не теряется |
| Удаление черновика: отказ, затем подтверждение | Отказ сохраняет ввод; подтверждение очищает форму |
| Папка тестового хранилища временно заменена обычным файлом | Ввод остаётся в форме, видны ошибка и повтор; прежняя задача остаётся в списке |
| Закрытие ошибочного создания, возврат через Cmd+N | Сохраняются выбранная задача и несохранённый ввод в памяти |
| Cmd+W при ошибке записи, затем «Отмена» | Возвращается окно с тем же черновиком и ошибкой; предупреждение не открывается по кругу |
| Восстановление папки и повтор переименования | Новое название сохраняется; прежний факт выполнения не подменяется |
| Изменение приоритета в деталях | Значение в строке обновляется; отдельная кнопка сохранения не нужна |
| Чекбокс выполнения | Та же задача перемещается в выполненные, детали и приоритет сохранены |
| Полный выход и запуск после успешной записи | Название, выбранный приоритет, UUID выполнения и выполненное состояние сохранились; Cmd+N восстанавливает отдельный черновик |

Компоновка деталей просмотрена в нативном окне: графитовая тема, сиреневый акцент, правая панель, текстовые подписи приоритетов, читаемое многострочное название с emoji. Клавиатурные команды ввода, Enter, Escape и Cmd+N проверены реальным вводом.

## Исправления в ходе проверки

- Swift 6.2.3 аварийно завершался при генерации адаптера прямой ссылки на метод в setter Binding для TaskPriority. Явное замыкание устранило сбой; сборка с warnings-as-errors проходит.
- Повторный выбор строки после сохранения использовал старый снимок задачи. Детали теперь читают актуальную сохранённую запись; нативный сценарий повторён успешно.
- После закрытия последнего окна отмена предупреждения могла повторно инициировать выход. Повторная обработка выхода подавлена; отмена восстанавливает окно через штатное действие SwiftUI. Cmd+W → ошибка → Отмена проверен повторно.
