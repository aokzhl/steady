Tests use the agreed public `TaskWorkspace` boundary with real temporary SQLite, reopen and an injected clock. They cover long stored titles, a formatted note's plain-text projection, parent and child matches, retained project/label/period filters, true match counts, context-only parents without unrelated siblings, completed matches in the explicit all-tasks context, whitespace queries, no matches versus empty storage, data-space isolation and an unchanged active stopwatch during queries.

Search is transient. The pre-search preferences remain the durable navigation state, and Back restores their complete value, including selection, expanded parents, sidebar and report screen. No SQL migration or new persisted JSON fields are required.

## Native acceptance pending coordinator

The implementation agent did not launch the application. The coordinator will perform native acceptance on isolated data and independent Standards/Spec review before integration.

1. In a project with selected labels and Today, open search from the sidebar or ⌘F. Verify the field receives focus and the current filters stay visible.
2. Search stored parent/child titles and formatted notes, including the suffix of a long title. A matching child appears under its context parent without unrelated siblings or an inflated count.
3. Choose “Искать во всех задачах”; verify other projects/dates and completed matches are available, with the broader context visible.
4. Focus the search field and press Escape: the query clears. Press Escape again, or use Back, to restore the original project, labels, period, selection and expanded state. Repeat from Report and while a creation draft is visible.
5. Verify unmatched queries show “Поиск не дал совпадений”; a genuinely empty database shows “Задач пока нет”.
6. While a tool is active, search/select results and return; verify its owner and running/paused state remain unchanged. Verify note Enter/arrows and the More popover keyboard handling still work.
