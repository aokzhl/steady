# Issue #6 — task notes

Verified 2026-11-14 09:15 UTC in `feat/issue-6-notes`. Source: [GitHub #6](https://github.com/aokzhl/steady/issues/6). Native blocker #3 is closed.

## Implementation

Creation and details contain an AppKit rich-text editor with bold, highlight, bullet-list and HTTP/HTTPS link commands. Enter inserts a newline; bullet paragraphs continue until an empty bullet is ended with Enter. List formatting preserves inline attributes. The note editor owns normal text input; Command-B/Command-K apply note commands. Empty notes have a placeholder; long notes scroll, and the surrounding panels scroll in short windows.

The editor exports standard RTF bytes plus an exact plain-text projection. `TaskNote` in Core imports Foundation only. SQLite schema 3 adds non-null `note_rtf` BLOB and `note_text` TEXT to tasks and creation drafts. Older records receive empty notes. Notes belong to tasks, and creation consumes the matching durable draft in the same transaction.

Each edit saves locally. Failed writes leave saved Core state untouched and retain current input in `WorkspaceEditor`, with the existing error/retry controls. A failed detail save keeps details open; a failed creation-draft save retains its note when the panel is hidden and reopened. Application termination uses the existing explicit retry/cancel/discard flow.
