# #11 — Контекст списка и восстановление

Публичный `TaskWorkspace.taskList(in:)` объединяет проект, несколько меток (исходно «любая», отдельно «все») и период. Результат содержит только совпавшие выполнения, группы с числом реальных совпадений и родителей как отдельный контекст. Неподходящие братья/сёстры не попадают в результат. Открытые дети выполненного родителя доступны в компактном контексте. «Все» показывает текущие/ближайшие открытые выполнения, «Выполненные» — завершённые; отдельный переключатель показывает завершённые в текущем периоде. Для Сегодня разовые просроченные и недельные дела без дня выделены отдельными группами, остальные сгруппированы по проектам и «Без проекта». Ограниченные периоды материализуются через `prepareTaskList(in:)` перед чтением.

В окне скрываемая панель содержит Все задачи, Отчёт, проекты и метки; периоды находятся над списком. «Ещё» открывается наведением, нажатием и клавиатурой и меняет период только после выбора недели/месяца. Проект, метки и период совместно видны в заголовке и подсветке. Все задачи/Сбросить фильтры очищают проект и метки, сохраняя период. Между проектами и метками период также сохраняется.

Миграция **13** добавляет запись предпочтений в SQLite конкретного пространства; глобальные UserDefaults не используются. Сохраняются контекст, экран, UUID выбранного выполнения, видимость деталей/панели и раскрытые родители. Сегодня вычисляется из текущих часов и зоны Mac, без сохранения абсолютной даты вместо относительного периода. Поставленные миграции 3–12 не изменены.

## Автоматическая проверка

Согласованная граница — публичный TaskWorkspace с реальными временными SQLite и повторным открытием. Три новых сценария проверяют совместную фильтрацию и контекст родителя без лишнего результата/счёта, восстановление в том же пространстве и изоляцию другой базы, изменение Сегодня при смене зоны, различимые пустые состояния, группы Сегодня, материализацию всех дней текущего месяца и завершённые выполнения.

`bash tooling/macos.sh test`: **110 тестов / 13 наборов** прошли. Точечные новые тесты прошли после наблюдённых красных циклов. `bash tooling/macos.sh check` (warnings-as-errors), `bash tooling/macos.sh build` (подписанное приложение) и `git diff --check` также прошли.

## Нативная проверка и границы

Implementer не запускал приложение: нативные hover/click/keyboard, восстановление и реальные переходы проверяет корневой агент в отдельной базе. Отчёт открывает существующую историю настоящих запусков; полная сводка/хронология остаются #25–26. Поиск #12 и календарь/сохранение вида #13 здесь не реализуются. Текущая сессия и её владелец не меняются при навигации; выбранное выполнение хранится отдельно. Существующие безопасные UUID-bindings детей сохранены. API не добавлен.

Публичное поведение и миграция 13 не менялись. После извлечения повторно прошли check, 110 тестов / 13 наборов, подписанная сборка и diff-check.

## Нативный проход и клавиатура «Ещё»

Корневой агент в отдельной QA-базе проверил «любая»/«все», контекст родителя без дополнительного результата и неподходящего соседа, сброс через Все задачи с сохранением периода, Выполненные, реальную 30-секундную запись в Отчёте и сообщение об отсутствии совпадений. Перед выходом сохранены Work/Сегодня, раскрытый родитель, выбранный UUID ребёнка и скрытая панель для проверки восстановления.

Первый нативный проход выявил, что SwiftUI `FocusState` не передаёт стрелки/Return пунктам «Ещё» при текущих настройках клавиатуры macOS. Вместо него добавлен локальный responder внутри самого popover, который после присоединения к окну получает фокус и обрабатывает только свои стрелки/Return/Escape. Глобальные перехватчики событий не устанавливаются. Открытие кнопкой теперь идемпотентно, чтобы клик после hover не закрывал меню. Повторную нативную проверку после сборки выполняет корневой агент.

## Итоговая нативная проверка координатора

Набор отдельных тестовых данных создан через публичные команды TaskWorkspace: два проекта, две метки, просроченное и недельное дела, родитель с совпавшим ребёнком/неподходящим соседом, завершённое выполнение и реальный результат команд секундомера 30 секунд. Приложение проверялось через CUA. Для этого QA bundle получил отдельный identifier и привязку к временной базе через [LSEnvironment](https://developer.apple.com/documentation/bundleresources/information-property-list/lsenvironment); прямой CLI-запуск также передавал STEADY_DATA_DIRECTORY.

Проверены группы Сегодня, совместные проект+метки+период, различие «любая»/«все» (при пересечении исчезает дело только с одной меткой), контекст родителя без его чекбокса/лишнего счёта и без неподходящего соседа. Все задачи сбрасывает частные фильтры и сохраняет период. Переход между проектами сохраняет период; сочетание без совпадений даёт соответствующее сообщение. Выполненные показывает завершённое дело; Отчёт показывает существующий 30-секундный результат.

После выхода/запуска восстановились Работа/Сегодня, скрытая боковая панель, раскрытый родитель и выбранный UUID ребёнка с его деталями. Предварительная клавиатурная проверка Ещё выявила отсутствие реального фокуса; исправление c7ec294 добавило локальный responder. На итоговой сборке явное нажатие выбирает месяц, Up/Return выбирает неделю, быстрые Down/Return — месяц; Up/Escape не меняет применённый месяц. После закрытия меню Enter в заметке создаёт новую строку и не перехватывается.

110 тестов в 13 наборах, warnings-as-errors check, signed build и diff-check успешны. Независимые Spec/Standards повторные ревью общей границы периода и клавиатурного исправления дали 0 замечаний. Поиск, календарь и полные отчёты остаются следующими срезами.
