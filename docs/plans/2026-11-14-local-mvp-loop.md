# Steady: локальный цикл MVP #4–#26

Пользователь 14 ноября 2026 года поручил выполнить все оставшиеся тикеты без API, применять быстрые модели и независимых субагентов, самостоятельно сливать PR после успешных проверок и ревью. Superpowers отключён. #2 и #3 завершены; #27–#36 не входят в этот цикл.

## Принятые решения после grilling

Все Q1–Q8 подтверждены ответом «время храни в utc, дальше все да».

1. Фактические моменты начала/окончания/выполнения хранятся в UTC; длительности в секундах. Плановый день — календарная дата, а не момент времени. Часовой пояс/границы истории сохраняются отдельными метаданными. Сегодня и новые периоды следуют текущей зоне Mac; начатая сессия использует свою начальную календарную зону для отчёта, исторические данные не пересчитываются.
2. Начало серии по умолчанию Сегодня, допустима прошедшая дата. Прошедшие положенные выполнения — невыполненные без долга. Недельная задача посреди недели получает выполнение текущей недели.
3. При изменении серии выполненные экземпляры и экземпляры с сохранённой работой сохраняются. Остальные с выбранного экземпляра следуют новому правилу. Явные индивидуальные переносы сохраняются.
4. Перенос на день с другим выполнением той же задачи оставляет два независимых выполнения с отдельными UUID/состояниями. Недельный перенос за пределы собственной недели отклоняется с объяснением.
5. При запуске Таймера с Не задано запросить длительность; после подтверждения сохранить как настройку этой задачи для следующих запусков. До подтверждения не запускать.
6. При аварии допускается потеря не более последней секунды незафиксированной работы. Явные команды фиксируются сразу. Ошибка локального сохранения ставит инструмент на паузу и предлагает повтор. Перезапуск восстанавливает на паузе без начисления отсутствия.
7. Одна панель на встроенном экране с вырезом; без него или при закрытой крышке остаётся строка меню. Возвращение экрана восстанавливает панель. Дополнительная верхняя панель на внешнем экране не добавляется.
8. Удаление активного владельца требует подтверждения остановки, сохраняет фактическую работу/подпись/историю. Отмена удаления возвращает задачу без автоматического запуска часов.

## Реализация и проверка

Приоритет источников: явные решения пользователя → MVP и актуальный макет 11 ноября → действующие ADR и согласованные правила handoff. Наличие дополнительных режимов в HTML не расширяет MVP.

Один тикет — отдельный проверяемый срез и PR. Проверять native blocked_by перед стартом. Независимые срезы допустимы параллельно в отдельных worktree, изменения общего хранилища интегрируются последовательно. Корневая координация сохраняет совместимость миграций.

Согласованная автоматическая граница — публичный TaskWorkspace с реальной временной SQLite и повторным открытием. Для времени допустимы управляемые часы через уже существующий now/calendar. Нативные взаимодействия дополнительно проверяются в приложении с отдельными тестовыми данными. Ревью Standards и Spec независимо до слияния.

Технические детали агент выбирает самостоятельно. Новое существенное продуктовое решение сначала предложить пользователю; уже согласованные решения повторно не спрашивать. Цикл останавливается после #26; API не реализуется.

## Уточнение для недельного пропуска (#9)

При явном пропуске недельного выполнения, которому принадлежит активный инструмент, пользователь сначала вручную нажимает Stop. Это правило действует и для сессии на паузе: попытка пропуска отклоняется с объяснением «Сначала нажмите Stop», без изменения сессии, фактов и состояния выполнения. После Stop пропуск доступен, сохранённый фактический результат остаётся у того же выполнения. Пропуск другого выполнения не влияет на активный инструмент. Пользователь подтвердил этот вариант отдельно после исходных Q1–Q8.
