# Контракты API и генерация клиентов через OpenAPI

Каждый сервис описывает свой API в FastAPI и экспортирует OpenAPI-контракт в `contracts/`. На его основе генерируются сетевые клиенты и модели запросов и ответов для Swift, TypeScript и Android по мере появления соответствующих приложений. Это уменьшает ручное дублирование сетевого кода между платформами; внутренние модели и поведение приложений остаются собственными для каждой платформы.

В проверках репозитория отслеживается актуальность экспортированных контрактов и сгенерированных клиентов. Конкретные генераторы ещё не выбраны; генерация не заменяет проверку поведения API и совместимости с уже выпущенными приложениями.
