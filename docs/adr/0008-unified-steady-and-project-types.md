# Единое приложение Steady с возможностями по типу проекта

Дата: **2026-11-09**. Статус: **принято**. Заменяет [ADR-0001](0001-independent-apps-shared-account.md) в части самостоятельных приложений Focus/Fit.

Название приложения остаётся **Steady**. Focus — инструмент фокуса внутри него, тренировки и исламское направление также развиваются внутри общего приложения. Ислам — одна из возможностей продукта, поэтому название всего приложения не привязывается к этому направлению; обсуждавшийся вариант Amal не выбран.

Вместо семейства отдельных приложений пользователь выбрал общие проекты, задачи и календарь. При создании проекта предполагается выбор его типа, например обычный, тренировки или исламское направление, с соответствующими специализированными возможностями. Конкретные экраны тренировок, рекомендации, правила запуска и результаты требуют дальнейшей проработки; примеры ассистента не становятся автоматически принятыми требованиями.

Текущий MVP сохраняет ранее закреплённый объём задач, фокуса, календаря, отчётов и доставки результатов. Тренировки и специализированные исламские возможности относятся к дальнейшему развитию; уточнение названия само по себе не добавляет их в MVP.

Выбор единого клиентского приложения не отменяет микросервисы, SwiftUI/AppKit, FastAPI, общий аккаунт и монорепозиторий. sso и Focus остаются техническими именами сервисов MVP; владение данными будущих специализированных проектов уточняется при их проектировании. Принятый снимок дизайна от 7 ноября сохраняется с историческими именами файлов и подписями Focus.
