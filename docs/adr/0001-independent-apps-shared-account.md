# Самостоятельные приложения Steady с общим аккаунтом

**Статус: заменено 2026-11-09 решением [ADR-0008](0008-unified-steady-and-project-types.md).** Текущее направление — единое приложение Steady; Focus, тренировки и исламские возможности находятся внутри него. Ниже сохранено первоначальное решение.

Steady помогает регулярно заниматься важным и видеть прогресс. Focus для сосредоточенной работы и Fit для тренировок будут самостоятельными приложениями с общим аккаунтом; в будущем появится возможность общего обзора активности. Сейчас разрабатывается Focus.

Первый этап — личное использование рабочего MVP Focus, затем небольшая бета для других пользователей. Приоритет первой версии — удобная работа основных сценариев; детальная визуальная полировка следует позже. Срок и бюджет пока не заданы.

Выбран вариант связанных приложений: он позволяет развивать продукты независимо, сохраняя общую принадлежность пользователя к экосистеме. Рассматривались также семейство приложений, объединённых только брендом, и единая система планирования с общими целями и расписанием.

Выбор общего аккаунта не определяет способ авторизации. Последующее решение о микросервисах и принадлежности данных записано в [ADR-0002](0002-microservices-and-product-data.md), о работе Focus без регистрации — в [ADR-0003](0003-focus-without-registration.md).
