# Общие выполнения дел и одна активная сессия занятия

Дата: **2026-11-09**. Статус: **принято по ответу «все» на Q1–Q3** в [обсуждении](../design/steady-unified-projects-discussion.md).

Проект, общий список и календарь отображают те же выполнения дел без независимых копий. В общем списке одна строка на тренировку, упражнения находятся внутри неё; каждый намаз или самостоятельное занятие представлено отдельным делом. Расписание принадлежит конкретному делу/занятию, мастер создания проекта помогает настроить его, проект не добавляет конкурирующее расписание.

В Steady одна активная сессия занятия. Помодоро и специализированное выполнение работают в её рамках; время тренировки, упражнения, отдых и паузы описывают части и общий ход той же сессии. Вложенные показания времени не создают независимые результаты и не должны удваивать общий итог.

Это продолжает [ADR-0008](0008-unified-steady-and-project-types.md). Предложенный затем выбор «помодоро или секундомер», значения по умолчанию, переходы режимов, ротация программ и серверный обмен специализированными данными требуют отдельных решений. Состав текущего MVP этим ADR не расширяется.
