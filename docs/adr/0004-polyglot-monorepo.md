# Монорепозиторий Steady для разных платформ

Приложения и backend Steady будут разрабатываться в одном репозитории, рассчитанном на веб, macOS, Android и серверные сервисы. Это позволяет держать документацию и связанные изменения рядом и организовать удобную разработку экосистемы одним разработчиком.

Клиентские приложения группируются сначала по продукту, затем по платформе: `apps/focus/macos/`, `apps/focus/web/`, `apps/focus/android/`. Сервисы размещаются в `services/sso/` и `services/focus/`. Целевая структура также предусматривает `contracts/` для опубликованных контрактов API, `packages/` для общих библиотек по мере необходимости, `tooling/` для автоматизации, `infra/` для инфраструктуры и `docs/` для документации. Будущие компоненты добавляются по мере разработки, без обязательного создания пустых проектов заранее.

Монорепозиторий сохраняет требование независимого развёртывания микросервисов. У компонентов собственные зависимости, настройки и проверки. Для общих команд разработки и фиксации версий инструментов выбран mise; команды вызывают собственные инструменты соответствующих платформ. Xcode и Android SDK настраиваются отдельно. Конкретные команды, менеджеры зависимостей компонентов и порядок реализации новых платформ ещё не согласованы.

Локальные sso, Focus и PostgreSQL запускаются через Docker Compose под общей командой mise. Исходники сервисов подключаются из репозитория для обновления кода при разработке, данные PostgreSQL сохраняются между перезапусками окружения. Приложение macOS работает на хосте и обращается к локальному backend. Это решение относится к локальной разработке; способ размещения production ещё не выбран.
