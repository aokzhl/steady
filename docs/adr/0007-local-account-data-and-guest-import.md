# Отдельные локальные данные аккаунтов и перенос из гостевого режима

Локальные данные Focus разделяются по аккаунтам Steady; гостевой режим имеет отдельное пространство данных. После выхода история и неотправленные результаты сохраняются на Mac с принадлежностью к исходному аккаунту. Интерфейс другого аккаунта или гостевого режима их не отображает. Выход очищает данные авторизации на устройстве; правила серверного отзыва сессий требуют отдельного решения.

Очередь аккаунта A не отправляется при входе в B и ожидает повторного входа в A. Это сохраняет неотправленные результаты и предотвращает их отправку другому пользователю.

При выходе из аккаунта или переключении с A на B текущая сессия автоматически ставится на паузу и сохраняется за исходным аккаунтом. В B приложение показывает данные и состояние B. После повторного входа в A пользователь может продолжить сохранённую сессию с оставшегося времени. Смена аккаунта сама по себе не завершает сессию и не переносит её результат другому пользователю. Перенос активной гостевой сессии при первом входе требует отдельного решения: согласованный перенос гостевых данных включает профили, задачи и результаты.

При первом входе, включая вход в существующий аккаунт, приложение предлагает перенести гостевые профили, задачи и результаты. Только после явного согласия они закрепляются за выбранным аккаунтом и отправляются на сервер. Повторная попытка переноса не создаёт дубликатов. При отказе данные остаются в гостевом пространстве.
