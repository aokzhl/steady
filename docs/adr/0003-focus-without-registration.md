# Focus доступен без регистрации

Focus позволяет запускать таймер, создавать профили и сохранять результаты на Mac без регистрации. Вход в аккаунт Steady добавляет синхронизацию, чтобы основная польза приложения была доступна сразу.

При первом входе пользователь может перенести локальные данные в аккаунт. Перенос требует явного согласия; правила переноса, отделения данных разных аккаунтов и паузы таймера при выходе или смене аккаунта описаны в [ADR-0007](0007-local-account-data-and-guest-import.md). Поведение активной гостевой сессии при первом входе пока не согласовано.
