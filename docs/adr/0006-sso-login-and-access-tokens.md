# Вход через sso и самостоятельная проверка доступа в Focus

Собственный sso на FastAPI предоставляет регистрацию по email и паролю, подтверждение email, вход, выход, восстановление пароля и сохранение входа между запусками приложения. Пользователь выбрал этот способ вместо одноразового кода на email. Вход через внешних провайдеров отложен.

После входа sso выдаёт короткоживущий подписанный JWT для доступа и refresh token для продления входа. Focus самостоятельно проверяет подпись JWT, срок действия и назначение, затем разрешает доступ только к данным соответствующего пользователя. Обновление токенов выполняется через sso. Это уменьшает связанность сервисов по сравнению с обращением к sso при каждом запросе.

При недоступности sso запросы с действующим токеном могут обрабатываться Focus, если ключ проверки уже известен. Когда токен истекает и обновление недоступно, синхронизация ожидает восстановления sso, а локальный таймер продолжает работать. Длительности токенов, механизм обновления ключей, правила ротации refresh token и отзыва сессий ещё не согласованы.
