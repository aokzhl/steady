# Focus для macOS на SwiftUI

Дата: 2026-11-05. Статус: архивный черновик, не используется как текущая спецификация.

Текущий сводный документ — [MVP Steady Focus](../../MVP.md), решения об экосистеме, backend и работе с аккаунтами находятся в [ADR](../../adr/0001-independent-apps-shared-account.md). Этот черновик предшествует выбору FastAPI и микросервисов; его локальная архитектура и предложенные параметры не являются текущими требованиями.

Focus — личное приложение для продуктивности без бэкенда. Первый инструмент — свободный помодоро с настраиваемыми профилями, задачами, статистикой и панелью у моноброви MacBook. Пользователь выбрал второй визуальный вариант, «Рабочее пространство», и нативный SwiftUI вместо Tauri.

## Подтверждённые требования

- Приложение для личного использования на macOS.
- Панель у моноброви раскрывается при наведении курсора. В свёрнутом состоянии отображается важная информация о текущей сессии.
- Есть полноценное основное окно.
- Свободный режим: пауза, продолжение, остановка, произвольные перерывы и изменение длительности.
- Собственный список задач. Привязка задачи к сессии необязательна. Напоминаний о задачах нет.
- Вместо рутин — профили «Учёба», «Работа» и пользовательские профили, настраиваемые и запускаемые вручную.
- При сне или блокировке Mac таймер автоматически ставится на паузу.
- В раскрытой панели есть «Пауза», «Остановить», «Отдых» и переход к основному окну.
- При наведении на время или кнопку изменения времени открывается всплывающий выбор от −20 до +20 минут.
- Изменение работает как приращение к оставшемуся времени; повторное применение повторяет приращение.
- В будущем добавляются другие инструменты продуктивности.

## Предлагаемый объём первой рабочей версии

Эта граница — предложение исполнителя, а не новое требование пользователя. Первая сборка должна позволять пользоваться таймером ежедневно: работать с задачами и профилями, менять время из моноброви, переходить на отдых, сохранять историю и восстанавливать данные после перезапуска.

В сборку входят основной интерфейс, панель у моноброви, движок таймера, задачи, редактируемые профили, локальные данные, базовая статистика, настройки, звуковой сигнал завершения и локальные уведомления об окончании этапа. Уведомления о задачах отсутствуют. Простые фоновые звуки можно включить в профиле; исходный вариант — генерируемый локально шум без загрузок из интернета.

Блокировка приложений и сайтов, интеграция с системным режимом «Фокусирование», календарь, привычки, заметки и буфер обмена остаются в направлении развития. Они требуют отдельного проектирования поведения и системных разрешений и не должны отображаться как якобы работающие функции первой сборки. Согласование этого документа также согласует предложенную границу первой версии.

## Рассмотренные подходы

| Подход | Преимущества для проекта | Издержки | Решение |
| --- | --- | --- | --- |
| SwiftUI + AppKit | Прямая работа с окнами macOS, системными событиями и панелью; единый язык | Интерфейс строится заново по HTML-макету; перенос на Windows требует другой реализации | Выбран пользователем |
| Tauri + TypeScript + Rust | Веб-интерфейс, общие компоненты, основа для других ОС | Два языка, IPC между окнами, отдельная интеграция с AppKit для моноброви | Обсуждён и не выбран |
| Electron + TypeScript | Веб-интерфейс и развитая экосистема | Дополнительная архитектура Chromium для небольшой системной утилиты | Не выбран |

HTML-макет `focus-workspace-increments-b82d.html` в папке артефактов чата — визуальный ориентир, не код приложения. В репозитории не должно быть WebView, веб-сервера или зависимости от этого артефакта для запуска.

## Платформа и сборка

- Swift 6, SwiftUI, AppKit, Foundation, Observation, SwiftData, Swift Charts, AVFoundation и UserNotifications.
- Минимальная версия macOS — 14, предложенная ранее исполнителем; проверенная среда пользователя — macOS 26.6.2 на Apple Silicon.
- Без сторонних зависимостей в начальной реализации.
- Swift Package Manager: библиотека доменной логики, исполняемый target приложения и тестовый target.
- Скрипт сборки создаёт настоящий `Focus.app` с `Info.plist`, стабильным bundle identifier и исполняемым файлом из release-сборки.
- Доступные инструменты: Swift 6.2.3 и macOS SDK из Command Line Tools. Полный Xcode сейчас не установлен. Для проверки использовать `swift build`, `swift test` и запуск `.app`; не объявлять `xcodebuild` пройденным.
- Начальная сборка для локального использования. Публикация, notarization, установка системных компонентов и Mac App Store не входят в эту работу.

## Структура приложения

`FocusCore` содержит модели состояния таймера и переходы между ними, правила изменения времени, расчёт статистики и тестируемые интерфейсы времени/хранения. Он не зависит от SwiftUI и AppKit.

`FocusApp` содержит SwiftUI-экраны, общий observable-контроллер приложения, SwiftData-хранилище, координатор окон AppKit, сервис системных событий, звук и уведомления.

Основное окно и панель используют один экземпляр контроллера сессии. Панель не создаёт собственный таймер. Открытие и закрытие окна не начинает новую сессию.

Работа со SwiftUI и AppKit выполняется на главном actor. Состояние таймера изменяется последовательно. Операции сохранения имеют обработку ошибок; при ошибке интерфейс показывает проблему и не заявляет, что данные сохранены.

## Основное окно

Дизайн — выбранный тёмный вариант с графитовым фоном, мягким сиреневым акцентом и системной типографикой. Это собственное оформление поверх нативных элементов, без принудительного применения системных стеклянных материалов.

Боковая навигация: «Фокус», «Задачи», «Профили», «Статистика», «Настройки». Скрытые будущие инструменты не занимают неработающие пункты навигации.

Экран фокуса показывает список задач, текущую задачу, кольцевой таймер, профиль, этап, управление и быстрый выбор профиля. Статистические показатели берутся из сохранённых сессий, а не из демонстрационных значений макета.

Основное окно можно открывать, сворачивать, растягивать и переводить в полноэкранный режим. Полноэкранный режим основного окна и поведение компактной панели поверх других полноэкранных приложений — разные сценарии; проверяются отдельно.

## Панель у моноброви

Панель реализуется через AppKit `NSPanel` без обычной рамки; SwiftUI-контент размещается через `NSHostingView`. Отдельный координатор отвечает за позиционирование, уровень окна, раскрытие и закрытие.

Геометрия рассчитывается из `NSScreen.safeAreaInsets` и доступных областей сверху. Нельзя рисовать поверх физического выреза камеры; информация располагается по бокам и ниже него. Размеры учитывают масштабирование и смену экрана.

В свёрнутом виде: профиль, оставшееся время и состояние сессии. В раскрытом: задача, состояние, индикатор прогресса, «Пауза/Продолжить», «Отдых/К работе», изменение времени, «Остановить», номер сессии и открытие основного окна.

Наведение раскрывает панель без активации основного окна. Уход курсора закрывает её с небольшой задержкой, отменяемой при возвращении. Всплывающий выбор времени считается частью области взаимодействия: переход в него не закрывает панель. Для ввода с клавиатуры панель может получать фокус; Escape закрывает всплывающее меню.

На экране без выреза панель располагается по центру верхнего края. Эта резервная позиция — решение исполнителя для разработки, внешних дисплеев и смены основного монитора.

После изменения конфигурации дисплеев панель перемещается на основной экран. На нескольких дисплеях в первой версии существует одна панель. Доступ через menu bar остаётся независимо от наличия выреза.

Поведение с Spaces, Mission Control, автоматическим скрытием menu bar и полноэкранными приложениями проверяется первым техническим этапом. Не использовать private API, чтобы обещать заведомо неподтверждённое поведение поверх системных окон.

## Модель таймера

Состояние: `idle`, `running`, `paused`, `finished`. Этап: `focus`, `shortBreak`, `longBreak`. Признак причины завершения различает естественное окончание и ручную остановку.

Движок хранит идентификатор сессии, профиль и его снимок настроек, необязательный ID задачи, этап, время начала, остаток и накопленное активное время. Изменение профиля в редакторе не меняет уже запущенную сессию.

Остаток вычисляется из опорного времени и продолжительности, а не из числа секундных callback. Периодические обновления только обновляют отображение и проверяют переходы. Для активного отсчёта используется монотонный источник времени; для истории и восстановления сохраняются календарные даты.

### Переходы

- Старт создаёт рабочую сессию из выбранного профиля. Сессия может идти без задачи.
- Пауза фиксирует остаток; продолжение создаёт новую опорную отметку времени.
- Остановить завершает текущую сессию как прерванную, сохраняет фактическое активное время и переводит движок в idle. «Остановить» не отмечает задачу выполненной и не считает сессию полностью завершённой.
- Отдых во время фокуса сохраняет остаток фокуса и запускает короткий перерыв профиля. «К работе» восстанавливает сохранённый остаток. Ручной отдых сам по себе не увеличивает счётчик завершённых помодоро.
- Естественное окончание фокуса сохраняет завершённую сессию, увеличивает счётчик цикла и выбирает короткий или длинный перерыв. Автоматический старт следующего этапа зависит от профиля; исходное значение — выключен.
- При выключенном автопереходе следующий этап ожидает ручного старта; счётчик не увеличивается повторно при повторном отображении finished.
- Естественное окончание ручного отдыха возвращает к сохранённому фокусу; при выключенном автопереходе фокус ожидает продолжения.
- Остановка во время ручного отдыха завершает всю текущую последовательность; возвращение к прежнему остатку после остановки не предлагается.
- Выбор другого профиля во время сессии только готовит следующий запуск. Замена текущей сессии требует явного действия «Начать заново» и сохраняет предыдущую как прерванную.

### Изменение времени

При наведении на отображение времени или кнопку изменения открывается popover. В нём: значение от −20 до +20 минут, шаг 1 минута, кнопки −/+, ползунок, быстрые значения, предпросмотр остатка и применение. Значение по умолчанию +5 минут.

Выбор значения и применение — разные действия. Перемещение ползунка не меняет сессию. «Применить» меняет текущий этап один раз. Основная кнопка после этого сохраняет выбранный знак/величину и повторяет приращение по клику.

Формула: `newRemaining = max(0, oldRemaining + deltaMinutes * 60)`. Верхняя граница +20 относится к одному действию; повторное применение может продлевать сессию дальше. Нулевое приращение не применяется. Активное время статистики не увеличивается от добавленных минут.

Если вычитание доводит остаток до нуля, этап завершается как сокращённый пользователем. Это событие не считается полной завершённой рабочей сессией; автопереход отключается для этого события и следующий этап ожидает ручного старта. Для отдыха предлагается возвращение к фокусу.

Изменение доступно в running и paused, не запускает paused-сессию автоматически и не применяется в idle/finished. Диапазон и ограничения проверяет движок, не только UI.

## Сон, блокировка и восстановление

При сне системы или отключении экрана работающая сессия ставится на паузу и сохраняется. Основные сигналы — уведомления `NSWorkspace` о сне системы/экранов и деактивации пользовательской сессии.

Мгновенная блокировка без сна экрана требует отдельной проверки на Mac пользователя: нельзя считать `sessionDidResignActive` гарантированным событием любой блокировки. Платформенный адаптер должен отдельно обнаруживать блокировку; если для этого понадобится недокументированное уведомление macOS, решение и его ограничение фиксируются до объявления требования выполненным. Не запрашивать разрешения Accessibility или Screen Recording для таймера без доказанной необходимости.

На пробуждении и разблокировке автоматического продолжения нет. Это предложение исполнителя: пользователь явно продолжает сессию.

При закрытии основного окна приложение продолжает работать через панель и menu bar. Явный Quit завершает процесс, сохранив снимок. При повторном запуске сохранённая сессия восстанавливается в paused, не считая время выключенного приложения работой.

## Данные

SwiftData хранит `TaskItem`, `FocusProfile`, `SessionRecord` и снимок активной сессии. Настройки оформления и поведения — UserDefaults/AppStorage. CloudKit выключен. Данные размещаются в стандартном Application Support приложения.

- Задача: UUID, название, статус, порядок, даты создания/завершения. Один общий список; редактирование, завершение, удаление. Напоминаний и календарных сроков нет.
- Профиль: UUID, название, SF Symbol, цвет, длительность фокуса, короткого и длинного перерыва, количество сессий цикла, автопереход, звук окончания и фоновый звук.
- История: UUID, ID/снимок профиля, необязательный ID/снимок названия задачи, этап, даты, активные секунды, причина завершения.
- Снимок: состояние движка, остаток этапа и сохранённый фокус при ручном отдыхе.

Начальные профили: «Работа» 50/10, «Учёба» 40/10, «Быстрая сессия» 25/5; длинный перерыв 20 минут после четырёх сессий. Это редактируемые исходные значения исполнителя.

Длительности в редакторе: фокус 1–240 минут, перерывы 1–120 минут, цикл 1–12 сессий. Название непустое. Удалённый профиль или задача не уничтожают исторические записи. Последний профиль удалить нельзя; текущая сессия работает по своему снимку.

Снимки сохраняются при каждом действии и системной паузе; история — при завершении. Писать в базу каждую секунду не требуется. Для аварийного завершения допустима потеря последних секунд отображения, но не сохранённых задач/профилей. Версионирование схемы закладывается с первого сохранения.

## Статистика, звук и настройки

Статистика за день/неделю: фактическое активное время фокуса, завершённые и прерванные сессии, распределение по профилям, дневной график. Время отдыха и паузы не включается. Локальный день рассчитывается в текущем часовом поясе; сессия через полночь распределяется по дням по активным интервалам.

Дневная цель задаётся в минутах фокуса, исходно 120; показатель визуальный, без напоминаний о задачах. Не строить серии достижений и дополнительные механики привычек в первой версии.

Сигнал окончания, громкость и фоновый звук управляются локально. Уведомления касаются только окончания этапа; отказ в разрешении не мешает работе таймера, сигналу и визуальному состоянию.

Настройки: раскрытие панели, задержка закрытия, звук/громкость, дневная цель, отображение приложения в Dock. Menu bar предоставляет открытие основного окна, базовое управление сессией и Quit. Горячие клавиши основных действий работают при активном приложении; глобальные сочетания — отдельное расширение.

## Критерии готовности

1. Можно собрать и запустить `Focus.app` имеющимися Command Line Tools; в README есть точные команды.
2. Приложение не требует сервера, регистрации или подключения к сети.
3. Профили и задачи редактируются и сохраняются после повторного запуска.
4. Таймер синхронен в окне, панели и menu bar; действия −20…+20 корректны в running/paused.
5. Отдых сохраняет остаток фокуса; остановка не приравнивается к полной завершённой сессии.
6. Сон автоматически ставит сессию на паузу; восстановление не добавляет время сна в статистику. Блокировка проверена отдельно и её поддержка описана фактически.
7. Наведение раскрывает панель, переход к popover не закрывает её, клики и клавиатура работают.
8. Доступ к основному окну есть с панели и menu bar; закрытие окна не завершает процесс.
9. Статистика построена из реальных записей и различает завершение, остановку и сокращение до нуля.
10. Доменная логика проверена тестами переходов, временных расчётов, пауз, повторных приращений и восстановления. Есть интеграционная проверка сохранения и ручная проверка нативного UI.
11. Итоговый отчёт различает успешно выполненные проверки и сценарии, которые требуют Mac с вырезом/ручной блокировки/полноэкранного приложения.
