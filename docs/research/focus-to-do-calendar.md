# Focus To-Do: календарь и повторы

Дата проверки: **6 ноября 2026**. Дополнение к [основной заметке](focus-to-do.md). Сначала приведены публичные первичные источники, затем — непосредственные наблюдения установленного Mac-клиента и предложения для Steady.

## Подтверждено

1. **Mac поддерживает повторяющиеся сроки.** Издатель приводит пример «Every Monday». Это подтверждает повтор с привязкой к дню недели, но не раскрывает алгоритм следующего срока при позднем выполнении. [Mac App Store, описание издателя](https://apps.apple.com/us/app/focus-to-do-pomodoro-tasks/id1258530160?mt=12).

2. **Опубликованный Mac-интерфейс организован списками.** На просмотренном изображении видны Today, Tomorrow, This Week, Planned, All, Completed; в деталях — Due Date и Repeat. Календарная сетка задач на этом изображении отсутствует. Примерные даты внутри — сентябрь 2019 года: рекламный скриншот не доказывает устройство актуальной версии. [Скриншот издателя](https://is1-ssl.mzstatic.com/image/thumb/PurpleSource113/v4/37/0c/e1/370ce120-ac74-17d6-020f-c58a4ff0f872/4e5f5efa-9154-4e69-8ad6-8a4829133d1e_3.png/800x500bb.jpg).

3. **У мобильного клиента календарь заявлен явно.** История iPhone/iPad-приложения называет Calendar view в версии 7.0; описание также обещает просмотр *учтенного времени* в календаре. Это два заявления, которые нельзя автоматически приписать отдельному Mac-клиенту или считать доказательством недельной сетки будущих задач. [iPhone/iPad App Store](https://apps.apple.com/us/app/focus-to-do-focus-timer-tasks/id966057213).

4. **Сайт разделяет срок, повтор и отчет.** Due Date задает срок; Repeat избавляет от повторного ввода частых задач; история описана как учет времени и выполнений за день/неделю/месяц. Само наличие недельного отчета не устанавливает недельный планировщик. [Официальный сайт](https://www.focustodo.cn/?lang=en_US).

5. **Календарное повторение и недельная квота различаются.** RFC 5545 задает повторения через начальную дату и правило, включая частоту и выбранные дни недели. Вывод для обсуждения Steady: «каждый понедельник» определяет даты; «один раз в любую дату недели» задает иной пользовательский смысл. Это аналитическое разграничение, не утверждение о реализации Focus To-Do. [RFC 5545, §3.3.10](https://www.rfc-editor.org/rfc/rfc5545#section-3.3.10).

## Не установлено публичными источниками

Наличие полноценного календаря планирования в отдельном Mac-клиенте; содержимое его datepicker; наличие режима «через N дней после выполнения»; правила пропусков, просрочки и появления будущих повторов; перенос одного экземпляра/всей серии; поддержка недельной квоты. Упоминание Calendar events в общем описании Mac недостаточно для подтверждения конкретного календарного интерфейса. Нужна проверка установленного клиента. [Mac App Store](https://apps.apple.com/us/app/focus-to-do-pomodoro-tasks/id1258530160?mt=12).

## Проверка установленного Mac-клиента

Проверено основным агентом 6 ноября 2026 через интерфейс установленного Focus To-Do (`com.macpomodoro`), без чтения внутренних данных приложения. Это непосредственные наблюдения; ссылки выше относятся к публичным материалам. Задачи и значения настроек не сохранялись и не изменялись.

- Навигация содержит Today, Tomorrow, This Week, Planned и Completed. Открытый This Week показывает список, сгруппированный по дате, и итоги оценки времени, факта и завершений. Полноценная сетка планирования в просмотренных экранах и меню View не обнаружена; это не доказательство отсутствия функции во всех режимах.
- В Due Date открывается календарная сетка месяца с переходами между месяцами и кнопками Remove / OK. Конкретная дата не выбиралась.
- В Repeat открывается форма `every [число] [days / weeks / months / years]` с Remove / OK. Наличие дополнительных правил после выбора периода и поведение при пропуске не проверены. Меню закрыто без сохранения; исходное Repeat None сохранилось.
- В Pomodoro Timer наблюдаются: Pomodoro Length 25 Minutes; Short Break Length 5 Minutes; Long Break Length 15 Minutes; Long Break After 4 Pomodoros. Эти числа — текущие значения в открытом приложении, не установленные исследованием универсальные значения по умолчанию.
- Ниже расположены отдельные переключатели Auto Start of Next Pomodoro, Auto Start of Break и Disable Break. Также есть звуки окончания работы и отдыха, громкость сигналов, фоновый шум с отдельной громкостью. Во время проверки значения не переключались.
- General содержит звук завершения задачи, добавление новых задач сверху и переключатели видимости Focus Time Ranking, Forest, Group. Возможность скрыть дополнительные функции — полезный ориентир для удобства, не рекомендация добавлять их все в Steady.

## Предложения для обсуждения Steady

Это кандидаты, а не утвержденное изменение MVP. Уже выбранные профили, необязательный таймер и одна активная локальная сессия сохраняются как исходная основа.

- Календарь должен быть представлением тех же дел: список дня с полосой недели как спокойный основной вариант; недельная сетка по дням как дополнительный режим. Часовая сетка нужна, только если пользователь хочет назначать точное время.
- Разделить дату, на которую запланирована работа, крайний срок и правило повторения. Предлагать каждый день, будни, выбранные дни, каждые N дней/недель; недельную цель без фиксированного дня уточнить отдельно.
- Выполнение, пропуск и перенос относятся к конкретному повтору; редактирование должно явно различать один повтор и этот/будущие. Для ежедневных привычек пропуск не должен автоматически создавать растущий долг.
- Профиль помодоро: фокус, короткий/длинный отдых, длинный отдых после N завершенных интервалов; отдельные автозапуски работы и отдыха; понятная последовательность цикла. Предложение по умолчанию — ручной запуск работы и отдыха, без изменения уже работающей сессии при редактировании профиля.
- Общие параметры: звук/громкость, отображение таймера и моноброви, горячие клавиши. Подтвержденное ранее поведение сна/блокировки — пауза, после перезапуска — восстановление на паузе. Изменение оставшегося времени через инкремент −20…+20 минут остается действием текущей сессии.
- Для будущей реализации явно определить, что считается завершенным помодоро при остановке, отдыхе раньше срока и уменьшении времени; фактически затраченное время сохранять отдельно от количества завершенных интервалов.
